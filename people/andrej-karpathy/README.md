# Andrej Karpathy

GitHub: [karpathy](https://github.com/karpathy)

These files are direct agent-facing instructions from public Karpathy repositories.

- [`autoresearch/program.md`](autoresearch/program.md) is the runbook for an autonomous research loop. It defines setup, allowed edits, fixed evaluation, result logging, and the experiment loop.
- [`nanochat/.claude/skills/read-arxiv-paper/SKILL.md`](nanochat/.claude/skills/read-arxiv-paper/SKILL.md) is a Claude skill for reading an arXiv paper and writing a project summary.

`program.md` is not named `AGENTS.md` or `CLAUDE.md`. It is included because it directly supplies context and rules to an agent.
